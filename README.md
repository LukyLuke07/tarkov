# Tarkov Questkarte

Persönlicher Assistent für Escape from Tarkov als einzelne Webseite: Karten mit Quest-Zielen und Wegen, Profil mit Questbaum, Hideout, Inventar mit Lager-Scan und Verkaufsliste, Kultistenzirkel-Rechner. PvE, PvP und Season mit getrenntem Spielstand.

**Online:** https://lukyluke07.github.io/tarkov/

## Benutzen

- Alles läuft im Browser, nichts wird hochgeladen. Der Spielstand liegt im Speicher des Browsers.
- Fortschritt aus den Spiel-Logs: links „Logs-Ordner verbinden“ und den Ordner `Logs` im Tarkov-Verzeichnis wählen (Chrome oder Edge). Jede Sitzung wird über ihren Server dem Modus PvE, PvP oder Season zugeordnet.
- Lager scannen: im Reiter Inventar einen Screenshot mit Strg+V einfügen.
- Umziehen auf einen anderen Rechner oder Browser: links „Spielstand sichern“, dort „Spielstand laden“.
